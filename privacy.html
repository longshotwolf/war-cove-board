Paper Game

What this board does

This page shows the War Cove paper-trading game board: the live standings of a chat game played on the War Cove's Kick stream. The game runs on virtual points (sats) only — no real money is wagered, won, or lost anywhere in the game.

Data we collect

None. This page collects no personal data. There are no accounts and no sign-up on this page, no analytics, no advertising trackers, and no cookies set by this page. Playing the game happens in Kick chat under your own Kick account; this page only displays the game.

Data stored on your device

If you install the board as an app, your device stores only the app's static shell files (the app icon and install manifest) so it can open with the board's look. The board page itself and all game data are always loaded fresh from the network — game state is never cached. The board's watching-the-game counter keeps a random per-tab id in your browser's session storage; it is not linked to you and disappears when the tab closes.

Third parties

The page displays game standings published by The War Cove and live public market data for its chart. Those connections are between your device and the public feeds; we do not receive, log, or sell any information from them. No personal data is sold or shared with anyone.
